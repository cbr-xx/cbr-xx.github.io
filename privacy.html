プライバシーポリシー

最終更新日：2026年10月29日

本ポリシーは、個人利用の補助ツール「JSS rclone recovery」における Google ユーザーデータの取り扱いを説明します。

1. アクセスするデータ

Google Drive API の drive.file スコープを用い、このアプリが作成したファイル、またはアプリにアクセスが許可されたファイルと、その操作に必要なファイル名・識別情報・メタデータを扱います。Google Drive 全体を検索・収集する目的では使用しません。

2. 利用目的

利用者本人が指定した暗号化済みバックアップファイルの作成、保存、取得、復旧およびハッシュ照合のためにのみ利用します。広告、プロファイリング、データ販売には利用しません。

3. 保存と保護

バックアップの保存先は、利用者本人の管理する Google Drive 内の専用フォルダーです。認証情報を含む設定バックアップは rclone の設定ファイル暗号化を適用してから保存する運用とし、復号パスワードはバックアップとは分けて管理します。Google OAuth のアクセストークン・更新トークンは、接続に使用する rclone 設定または保護された実行環境内で扱います。

4. 第三者への提供

利用者の Google Drive とのファイル操作には Google のサービスを利用します。Google Drive の保存・通信・アカウント管理には Google のサービス条件とプライバシーポリシーも適用されます。本ツールの管理者は、Google ユーザーデータを広告主やデータブローカーへ販売・提供しません。

5. 保存期間・削除・アクセス権の取消し

ファイルの保持期間は利用者本人が決定し、Google Drive 上で対象ファイルを削除できます。また、Google アカウントのセキュリティ設定から本アプリへのアクセス権を取り消すことができます。アクセス権を取り消すと、以後のバックアップや復旧処理が利用できなくなる場合があります。

6. 公開ウェブサイト

この GitHub Pages サイトは説明とプライバシーポリシーの公開を目的としており、ログインフォームやバックアップファイルのアップロード機能を設けていません。サイトの配信に伴う技術的なアクセス情報はホスティング事業者 GitHub によって処理される場合があります。

7. お問い合わせ・変更

本ツールに関するお問い合わせ先は 開発者の GitHub プロフィール、または Google OAuth 同意画面に記載されたサポート連絡先です。運用内容が変わった場合には、このポリシーを更新します。
